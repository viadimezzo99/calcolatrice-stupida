# Calcolatrice Stupida

Calcolatrice in stile Android base, ma con qualche idea sbagliata di proposito.

## Cosa fa di strano

- **Tasti invertiti:** il tasto `+` moltiplica, la `×` somma, il `−` divide, il `÷` sottrae.
- **Aura:** ogni `=` cambia il contatore AURA in alto a sinistra, a caso.
- **Risultati random:** a volte al posto del numero compare un meme italiano (`SIGMA`, `CAPRA`, `TIPO COSÌ?`…) o un codice casuale tipo `K7QX2`.
- **Errori creativi:** dividere per zero non dà un errore normale.

## Scaricare l'APK

L'ultima versione è sempre qui:

https://github.com/OWNER/REPO/releases/latest/download/calcolatrice-stupida.apk

Sostituisci `OWNER/REPO` con il nome della repo (vedi la pagina di GitHub).

## Build

La build gira su GitHub Actions (`.github/workflows/build.yml`): a ogni push su `main` compila l'APK di debug e lo pubblica in una release.

Per installare su Android: apri il file e consenti l'installazione da origini sconosciute.
